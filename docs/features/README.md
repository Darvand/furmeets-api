# Features principales

Cada feature principal del proyecto tiene su carpeta con dos documentos:

- `plan.md`: resumen, decisiones de arquitectura, fases, **requerimientos no funcionales**, riesgos y preguntas abiertas.
- `todo.md`: lista de tareas ordenada, con criterios de aceptación, verificación, dependencias y alcance.

La fuente de verdad de los requisitos sigue siendo [SPEC.md](../../SPEC.md). Estos documentos solo lo descomponen en trabajo implementable.
